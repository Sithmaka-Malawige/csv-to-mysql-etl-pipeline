# CSV to MySQL ETL Pipeline

## Description

This project demonstrates a simple ETL (Extract, Transform, Load) pipeline using Python, Pandas, and MySQL.

The pipeline:

CSV File
→ Data Cleaning
→ MySQL Database

## Technologies

- Python
- Pandas
- MySQL
- SQL

## Features

✔ Read CSV file

✔ Remove missing values

✔ Remove duplicate records

✔ Convert data types

✔ Create MySQL table

✔ Insert cleaned data into MySQL

✔ Verify inserted data

## ETL Flow

↓

Pandas

↓

Cleaning

↓

SQL Query
